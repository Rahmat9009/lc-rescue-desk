# Shared design specification — LC Rescue Desk

> **Superseded in part by [`corrections.md`](corrections.md) (2026-10-11).** That document corrects the
> typography recommendation (now Source Serif 4 + Source Sans 3 + IBM Plex Mono), the brand colours
> (now `#023527` / `#478f81`, sampled from the supplied logo), the spacing scale, the 15px/16px body
> conflict, and the adaptive demonstration, which is now generated by the real domain functions rather
> than written. Read it alongside this file.

The machine-readable version of these tokens is `studies/tokens.css`, which both visual studies import **unchanged**.
That shared import is the proof of coherence: the landing hero and the case workspace are the same system, not two
designs that resemble each other.

---

## 1. The narrative, and how sections connect

One argument runs through the landing and continues into the workspace:

> **a conflict exists → we find it → we draft the correction → a reply arrives → the recommendation changes →
> a human decides, on the record.**

Three devices carry it, and they are the only connective tissue the design needs:

**Repeated content.** The same case — `LC-2026-1042`, deadline `2026-10-12`, carrier availability `2026-10-16` —
appears on the landing, in the hero's product frame, and in the workspace. A visitor who opens a case meets the
document they were just reading about. Nothing on the landing is invented for the landing.

**Repeated components.** `StageRail`, `SourceDiff`, `DeadlineStrip`, `ChangeChip` and `QuoteCard` each appear on
both surfaces with identical construction. The landing's workflow section (A4) uses literally the same `StageRail`
as the workspace header (B2). Recognition does the work that a visual motif would otherwise have to fake.

**Repeated alignment.** One 1180px measure, one 4px spacing base, one gutter. The hero headline's left edge, the
product frame's left edge, the case title and the first column of every `SourceDiff` all sit on the same line.
Scrolling from landing to workspace, nothing shifts laterally.

**Transitions.** Only state the user caused is animated — a disclosure opening, a correspondence card appearing, a
stage advancing. `--fast 140ms` for controls, `--slow 260ms` for content arriving. No scroll-triggered entrances,
no hover lifts. `prefers-reduced-motion` collapses both to 1ms.

Sections do **not** each get a visual identity. There are exactly two grounds — paper and one inverted forest band
(A5, the deadline demonstration) — and the inverted band is used once, because it marks the single most important
claim on the page.

## 2. Colour

Taken from the brand mark: `#0d3a2c` dark and `#5ba288` sage. Each status colour means exactly one thing everywhere.

| Token | Value | Means, and only this |
|---|---|---|
| `--paper` | `#fbfbf9` | Page ground |
| `--surface` | `#ffffff` | Raised: cards, document bodies |
| `--sunk` | `#f4f6f3` | Recessed: line-number gutters, label cells, secondary pane |
| `--forest` | `#0d3a2c` | Inverted ground. Used once on the landing, and for the rail |
| `--ink` / `--mute` / `--faint` | `#141a16` / `#5d6b62` / `#8a988f` | Primary / secondary / tertiary text |
| `--line` / `--line-soft` | `#dfe4df` / `#ebefe9` | The only two separators. **Never a shadow to separate** |
| `--pine` | `#15503a` | The required term; the authoritative value; the primary action |
| `--signal` | `#5ba288` | Brand accent. Quotation rules and the hero button only |
| `--rust` / `--rust-bg` | `#8e3b2e` / `#f9ece9` | **Conflict.** A value that breaks a term; a date past the deadline |
| `--ochre` / `--ochre-bg` | `#8a6516` / `#f8f1e0` | **Attention, not yet conflict.** Awaiting, assumed, unverified, synthetic |
| `--ok` / `--ok-bg` | `#1d6b45` / `#e8f1ea` | Passed *the implemented checks*. Never "safe", never "accepted by a bank" |

Two rules this product specifically needs:

- **A timing conflict is never drawn in a reassuring colour.** The current build renders the `conflict` recovery
  plan inside a green panel with a small red badge. The panel must be neutral; `--rust` marks the conflicting value.
- **`--ok` is bounded.** It means the checks this build implements passed. Every `--ok` surface carries the scope
  caveat beside it.

Contrast: `--mute` on `--paper` is the lightest text/background pair in the system and clears 4.5:1. `--faint` is
used only for ≥12px mono labels and axis ticks, never for prose.

## 3. Type

Two families, both SIL OFL, verified available. Full reasoning and the rejected alternative: `typography.md`.

- **Source Serif 4** — display, headings, all prose.
- **IBM Plex Mono** — document text, quotations, dates, amounts, versions, line numbers, labels, buttons.

The split is categorical: **what the product says is serif; what a document states or the system labels is mono.**

| Role | Token | Family / size / weight / leading |
|---|---|---|
| Hero headline | `--display-1` | serif, `clamp(34px,4.6vw,56px)` / 400 / 1.045 / `-.021em` |
| Section opener | `--display-2` | serif, `clamp(24px,2.8vw,34px)` / 400 |
| Latest action, case title | `--heading-1` | serif, 26px / 600 / 1.26 |
| Card title | `--heading-2` | serif, 17px / 600 |
| Prose | `--body` | serif, 17px / 400 / 1.62, max 62ch |
| Dense prose | `--body-sm` | serif, 15px / 400 / 1.6 |
| Label | `--label` | mono, 12px / 500 / `.07em` / uppercase |
| Data | `--data` | mono, 15px / 500, `tabular-nums` |
| Headline figure | `--data-lg` | mono, 22px / 500, `tabular-nums` |
| Document text | `--doc` | mono, 13.5px / 400 / 1.7 |
| Button | — | mono, 14px / 500 |

`tabular-nums` is mandatory on every date, amount, version and line number so columns align digit-for-digit.
Body floor is 16px; the current build's 15px body is below it and is corrected here.

## 4. Space, surface, radius, motion

**Space** — 4px base, only these steps: `4 · 8 · 12 · 16 · 22 · 30 · 44 · 64 · 96`. Page gutter `--s6`; block
padding `--s6`; related items `--s3`; unrelated blocks `--s5`.

**Surface** — three grounds only (`--paper`, `--surface`, `--sunk`), plus `--forest` used once. Elevation is
expressed by ground and hairline, never by shadow. The single allowed shadow is `0 1px 0 rgba(20,26,22,.03)` on the
hero product frame, to seat it on the page.

**Radius** — `--r-sm 5px` chips, marks, inputs · `--r-md 9px` cards, document frames · `--r-lg 14px` page-level
blocks. One radius per role; never one radius on everything.

**Motion** — `--fast 140ms` controls, `--slow 260ms` arriving content, `--ease cubic-bezier(.2,0,0,1)`. Only
user-caused state animates. Reduced motion collapses both to 1ms. *Exception (2026-10-11): the landing's
continuously moving thread field, with its own pause control and reduced-motion handling — see
[`threads-background.md`](threads-background.md). The workspace remains free of ambient motion.*

## 5. Shared components

Each is defined once and used on both surfaces.

**`SourceDiff`** — the component the whole product rests on. A 3-column grid: line-number gutter (`38px`, `--sunk`),
role label (`168px`), value (mono). The required row carries `--pine` text; the actual row sits on `--rust-bg` with
`--rust` text and the conflicting token wrapped in `<mark>`. Below 900px the label moves above the value and the
gutter stays — the line number is the point and must never be dropped. *From Semrush; see `references.md`.*

**`DeadlineStrip`** — a date axis with a `--pine` rule at the deadline and one point per availability; any point
past the rule is `--rust`. Point captions sit above the line, date ticks below, so the two label bands never
collide. Beneath the axis, the same values repeat as `KeyValueRow`s, so the information survives without the
graphic (and on mobile, where only the rows render). An unknown date renders `Not established` and plots no point —
never a guessed position. *From incident.io's Timestamps block + ClickUp's deadline rule.*

**`ChangeChip`** — `old → new` with the old value struck through at 55% opacity: `timing ~~unknown~~ → conflict`.
This is what replaces restating a whole plan. *From incident.io.*

**`StageRail`** — five stages joined by `›`, past in `--mute`, current in `--ink` with a 2px `--pine` underline,
future in `--faint`. A terminal status (`Specialist review required`) greys the rail and marks an off-ramp rather
than inventing a sixth stage. Used identically in the workspace header and the landing workflow section.

**`QuoteCard`** — sender, date, `authenticity unverified`, the verbatim quotation against a `--signal` left rule,
then the `ChangeChip`s for what it changed.

**`ClaimRow`** — `label — state`, used for correction requests, scope claims and readiness. One row, many states.
*From Revolut's verify checklist.*

**Also:** `Chip`, `KeyValueRow`, `Disclosure`, `Timeline`, `SourceView`, `FieldRow`, `DropTarget`, `Dialog`,
`EmptyState`, `InlineError`, `Skeleton`, `RelativeTime`, `Button/{primary,ghost,light}`, `Brand`, `Rail`,
`Breadcrumb`, `ProductFrame`, `SyntheticTag`, `OwnerChip`, `ActorChip`, `DocChip`, `VersionChip`,
`RecommendationBlock`.

## 6. Rules this product needs that a generic system would not

1. **Never state an unverified thing in a confident voice.** `--ochre` exists for assumed and unverified values and
   is used wherever the data is a counterparty statement rather than a commitment.
2. **Honest empty values.** A missing date renders `Not established` in its row. The row is never hidden, because a
   hidden row reads as "no problem". *Taken directly from incident.io's "Missing timestamps".*
3. **No raw ISO timestamps as headings.** `2026-10-11T04:57:52.925Z` is a machine value; `RelativeTime` renders
   `10-11 04:57` with the exact value on hover.
4. **Repeated writes are grouped into episodes.** 12 plan revisions that produced one material change render as one
   entry with the delta, never as 12 restatements.
5. **A value and its source line are never separated.** Any extracted value is displayed with its line number and
   quotation, or not displayed.
6. **Parallel parties are not numbered.** Exporter and carrier act concurrently; they carry document codes
   (`INV`, `B/L`), not `01` / `02`.
7. **Destructive or binding actions state what they bind, adjacent to the control.** "Approval binds invoice v1 and
   bill of lading v1. Nothing is sent to a counterparty."

## 7. What is not settled

- **The real logo.** The mark in `studies/tokens.css` and both studies is a stand-in traced from a screenshot.
  Needed as SVG plus a dark-background variant and the two exact brand hex values. The palette above is derived
  from that stand-in and should be re-derived from the original.
- **No photography or texture.** Harvey's hero rests on a photographic band; this spec has no licensed imagery and
  deliberately avoids it.
- **Self-host vs Google Fonts** is a deployment decision, not a licensing one — both families are OFL.
